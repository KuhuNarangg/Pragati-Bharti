# Sample Documents Directory

Place your test documents in this directory for demonstrating extraction and matching:

- `clean_question_paper.pdf`: Standard digital PDF with clear questions and options.
- `scanned_low_quality.jpg`: Imperfect scan for testing OCR fallback and review flags.
- `rotated_page.png`: Image requiring page orientation auto-correction.
- `answer_key.pdf`: Answer key document for testing document group association and matching.
